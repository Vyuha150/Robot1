## Summary

Of the 17 files >2MB found (excluding already-characterized bulk directories):
- **5 are real, live production assets** (KEEP) — the Piper TTS model and 4 gesture-recognition runtime files, all correctly LFS-tracked, all confirmed referenced by live code.
- **5 are the exact same real assets, duplicated only in the gitignored `frontend/dist/` build-output directory** — expected Vite behavior, zero action needed beyond the general `dist/` cache removal already covered in `STORAGE_OPTIMIZATION_REPORT.md`.

No duplicate model **formats** were found (e.g. no case of the same model shipped as both `.onnx` and `.tflite` for redundant reasons) — every "duplicate" here is either the expected build-output mirror or the one confirmed-dead asset set already covered in Phase 4.
